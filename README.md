### 🚀 YOLOv5 Real-Time Webcam Object Detection

A real-time webcam object detection application powered by **YOLOv5, PyTorch, and OpenCV**.

This project integrates **Google Colab** with browser-based webcam frame capture using **JavaScript**. Webcam frames are captured in the browser and processed using **Python, OpenCV, and YOLOv5** to detect objects in real time.

## 🚀 Getting Started

### 1️⃣ Clone the Repository

Open your terminal and run the following commands:

```bash
git clone https://github.com/abuki16/YOLOv5-Realtime-Detection.git
cd YOLOv5-Realtime-Detection
```

### 2️⃣ Open the Project in Google Colab

Open the project notebook (`.ipynb`) using **Google Colab**.

You can either:

- 📤 Upload the notebook directly to Google Colab.
- 🔗 Open the notebook from the GitHub repository using Google Colab.

Make sure you have downloaded or opened the complete project so that the required project files are available.

---

### 3️⃣ Enable GPU Acceleration

In Google Colab, go to:

**Runtime → Change runtime type → Hardware accelerator → T4 GPU**

Then click **Save**.

If a T4 GPU is not available, you can use another available GPU.

---

### 4️⃣ Install the Required Dependencies

Run the dependency installation cells provided in the project.

The project uses packages and libraries required for:

- 🤖 YOLOv5
- 🔥 PyTorch
- 👁️ TorchVision
- 🖼️ OpenCV
- 🌐 JavaScript webcam integration

---

### 5️⃣ Run the Project

Run the project files or notebook cells **in the required order**.

The application will:

1. 🎥 Access your webcam through the browser.
2. 🌐 Use JavaScript to capture webcam frames.
3. 📸 Capture individual webcam frames.
4. 🐍 Process the frames using Python.
5. 👁️ Process images using OpenCV.
6. 🤖 Run YOLOv5 object detection.
7. 🔍 Identify objects in the captured frames.
8. 📊 Display the detection results.

> ⚠️ **Note:** Your browser will ask for permission to access the webcam. Allow camera access for the application to work correctly.

     ↓

     ↓

     ↓
📸 Capture Frame
     ↓
🐍 Python
     ↓

     ↓

     ↓

     ↓
